# 知序课表

知序是一款独立的 Android 课表应用，把每周课程、上课时间和今日安排放在清晰的界面里。支持手动管理课程，也可以在支持的服务中完成登录后同步课表。

## 下载与安装

请在 [Releases](https://github.com/GEYUANwuqi/zhixu-schedule/releases) 页面下载正式版 APK。对外提供的安装包均应通过正式发布签名校验。

下载后按 Android 提示安装。升级时建议直接覆盖安装，以保留本机数据；更换签名或卸载重装可能无法保留原有数据，请提前备份重要信息。应用支持 Android 8.0 及以上版本，具体兼容情况以版本说明为准。

## 课表与课程

- 按周查看课程，周一固定在最左侧、周日固定在最右侧。
- 打开课表时切换到当前教学周，并高亮今天；左右滑动可以切换上一周或下一周。
- 支持多张课表，课程可手动添加、编辑、删除。
- 支持单双周、连续或不连续周次，以及节次、地点、教师和备注。
- 点击课程可查看详细信息。课程卡片上的教师独立成行，显示内容可按需选择。
- 学期第一周的起始日期和教学周数可自行调整；首次创建秋冬学期默认使用 8 月 24 日和 20 周。

## 个性化

在设置中可以选择青苔、海盐、暮樱、麦茶、远山五套内置配色，每套都搭配了背景、菜单、选中状态、小组件和默认课程颜色，点击即可整体切换。课程卡片可以按课程名称单独指定颜色，也可以恢复跟随主题；地点、教师、周次、节次和备注可按需显示。

应用背景与桌面小组件背景可分别设置。选择照片后先调整显示区域，确认后才保存；可以缩放及调整横向、纵向位置。图片保存在本机，不会因设置背景而上传。

小组件背景不透明度默认为 100%，可与自定义照片叠加调整，文字保持清晰。

## 今日课表小组件

提供 **3×3** 和 **4×3** 两种尺寸，其中 4×3 指横向 4 格、纵向 3 格。桌面启动器可能会调整实际大小。

小组件显示当天课程、时间、地点与教师。课程较多时可在列表内滚动查看；当天没有课程时显示空闲提示。可从应用设置或桌面的小组件列表添加。

## 同步与离线使用

通过应用打开服务提供方的真实登录页面，自行完成账号、密码及验证码操作。登录状态有效时可继续同步，失效后需要重新登录。同步结果保存到本机后可离线查看。

服务可用性、网络状态和账号权限可能影响同步结果。课程时间以实际安排为准；遇到临时调课可以手动修改。

「设置 → 学校同步 → 管理同步规则」支持按原始课程名、教师、教室、星期、周次、节次或备注完全匹配，只替换填写的字段，其余保持原值。例如将教室 G411 替换为建工4楼。规则在下次同步时生效，可新增、编辑、删除和调整顺序，多条命中时依次应用；手动编辑的课程继续保留。

## 导出与日历

- **JSON 导入与导出**：保存当前课表的学期、时间设置和课程详情。导入前校验并确认，新建独立课表，保留现有课表；文件不包含登录状态或图片背景。
- **图片导出**：生成包含必要时间及课程信息的 PNG，以单双周分表展示，便于保存或分享。
- **日历导入**：完整替换本课表专用日历内的日程，避免旧课程残留；其他日历不会被清空。使用此功能需要授予日历权限。

## 隐私与权限

在“设置 → 导出与日历”中可导出完整备份，保存所有课表、课程、同步规则、外观、小组件和通知设置。恢复前会展示备份名称、创建时间与内容摘要，经确认后替换现有数据。备份不包含应用背景、小组件背景及登录凭证，恢复时保留本机背景和登录状态。备份中含课程、教师等信息，请妥善保管。

设置中的“状态栏与通知”可开启今日课程常驻通知，查看当前课程或下一节课倒计时；课程提醒支持自定义提前 1–60 分钟，默认 20 分钟，可按课程选择是否提醒，并选择显示名称、时间和教室。两项默认关闭。权限管理提供通知、准时提醒、后台运行及日历设置入口；系统省电策略可能导致提醒延迟。

网络权限用于登录和同步；日历权限仅用于日历导入。设置背景使用系统照片选择器。应用在本机保存课表、设置及必要的登录状态，可在设置中清除登录状态。

反馈问题时，请勿附上密码、验证码、登录凭证或未经处理的个人信息。分享截图、课表图片和日历前，请检查其中是否包含不希望公开的课程、教师或地点信息。

## 关于与更新

在设置的「关于」中查看版本和项目许可证，访问项目页面或反馈问题。点击「检查更新」对比 GitHub 最新正式版与当前版本；发现新版本时显示版本号、发布时间和 Release 更新日志。点击「前往更新」打开对应发布页并启动 APK 下载。启动时检查更新默认关闭，可在关于页面自行开启。
